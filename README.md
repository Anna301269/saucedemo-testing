# SauceDemo — Функциональное тестирование (pet-проект)

Pet-проект по ручному функциональному тестированию учебного
интернет-магазина [SauceDemo](https://www.saucedemo.com/). Выполнен в
рамках самостоятельной подготовки.

## О проекте

**Цель:** отработать полный цикл ручного тестирования — от анализа
требований до оформления дефектов — на примере реального веб-приложения.

**Тестируемое приложение:** [www.saucedemo.com](https://www.saucedemo.com/)

**Особенность приложения:** SauceDemo предоставляет 6 разных учётных
записей (`standard_user`, `locked_out_user`, `problem_user`,
`performance_glitch_user`, `error_user`, `visual_user`), поведение
которых может отличаться.

## Что было сделано

- Составлен тест-план с описанием подхода, окружения и критериев
- Восстановлены требования к функционалу (т.к. официальной
  документации у приложения нет)
- Написаны тест-кейсы с трассируемостью к требованиям
- Проведено тестирование по подготовленным тест-кейсам
- Найденные дефекты оформлены в виде баг-репортов

## Инструменты

- Яндекс Браузер — тестовое окружение
- Markdown, Excel — оформление документации
- GitHub — хранение и версионирование материалов
